Single-file static site (image embedded as base64, no build step needed).

## Deploy on Vercel
1. Push this repo to GitHub.
2. Go to vercel.com → Add New → Project → Import this repo.
3. Framework preset: "Other" (or leave auto-detect — it's plain static HTML).
4. Build command: none. Output directory: root.
5. Deploy.

## Local preview
Just open `index.html` directly in a browser.
